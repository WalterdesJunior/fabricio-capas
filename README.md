# Fabrício Capas e Acessórios

Mini site da loja Fabrício Capas e Acessórios — atacado e varejo de capas, películas, carregadores, fones e acessórios para celular em Teresina - PI.

**Site no ar:** https://walterdesjunior.github.io/fabricio-capas/

## O que tem no site

- Botões diretos para WhatsApp, Instagram, avaliação no Google e localização no Maps
- Vitrine de categorias de produtos (cada uma abre o WhatsApp com uma mensagem pronta)
- Informações da loja e horário de atendimento
- Layout responsivo para celular, tablet, notebook e PC

## Tecnologias

HTML, CSS e JavaScript puros, sem dependências nem etapa de build.

## Estrutura

```
index.html   Página do site
style.css    Estilos e responsividade
script.js    Links da loja e pequenas interações
img/         Fotos e banners
```

## Como editar

- **Links da loja** (WhatsApp, Instagram, Google e Maps): bloco `CONFIG` no início do `script.js`.
- **Fotos**: substitua os arquivos em `img/` mantendo os mesmos nomes.
- **Textos e horário**: direto no `index.html`.

Para ver o site no computador, basta abrir o `index.html` no navegador.

## Publicação

O site é publicado pelo GitHub Pages a partir da branch `main`. Cada `git push` atualiza o link em cerca de um minuto.
